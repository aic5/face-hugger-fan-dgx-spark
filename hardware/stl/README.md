# Printable fan cover and arms

The STL files are planned but are not part of this first public repository snapshot.

When released, this directory should contain at least:

```text
fan-cover.stl
left-arm.stl
right-arm.stl
```

Please include the following with the geometry:

- source CAD files or a link to the editable design, when available;
- units and intended print orientation;
- material, layer height, wall/perimeter, infill, and support recommendations;
- required screws/inserts and assembly order;
- measured fit for the specific fan and DGX Spark surfaces;
- clearances around vents, ports, cables, fan blades, and the Pico antenna;
- license for the hardware design; and
- photos of the installed assembly from several angles.

Before use, inspect every print for cracks, warping, loose fasteners, blade
interference, blocked vents, and unstable contact with the DGX Spark. Printed
parts can soften or creep with temperature; material choice and validation are
the builder's responsibility.
